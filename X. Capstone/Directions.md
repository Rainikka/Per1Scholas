## FrontEnd

### React Installation & Initializaton

- To run npm packages
  `npm i -g npx`
  npm i rea
- Create React App
  `npm create vite@latest`

- Wrapper for React App
  `npm i react-redux @reduxjs/toolkit`

- React Router DOM for navigation and routing
  `npm i react-router-dom`

- Importin gMaterial Icons Library
  `npm i @mui/material @emotion/react @emotion/styled @mui/icons-material`

- Importing Material Table Grid
  `npm i @mui/x-data-grid`

  -Importing Dev Dependencies
  `npm i -D`

- Importing TypeScript for React Router DOM
  `npm i @types/react-dom@18.0.11`
