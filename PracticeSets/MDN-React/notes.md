# React Initializaton with Vite
- 1. npm create vite@latest moz-todo-react -- --template react 
- 2. cd moz-todo-react && npm i -y
- 3. npm run dev -- --open --port 3000
- 4. Replace in package.json: scrips:
    - - "dev": "vite", --> "dev": "vite --open --port 3000",
- 5. To run server: npm run dev
